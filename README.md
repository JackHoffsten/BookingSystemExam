# Booking System

A console application for creating, viewing, searching, and cancelling meeting room bookings.

## Requirements

- .NET 10 SDK

Run the following commands from the repository root.

## Run the application

```bash
dotnet run --project src/BookingSystem
```

## Run the tests

```bash
dotnet test
```
